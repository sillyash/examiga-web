# EX-AMIGA web

Vue 3 + TypeScript + Vite frontend.

## Install

```sh
npm install
```

## Run (dev)

```sh
npm run dev   # http://localhost:5173
```

## Other commands

```sh
npm run build        # type-check + production build
npm run type-check    # vue-tsc only
npm run lint          # oxlint + eslint --fix
npm run format        # prettier
```
